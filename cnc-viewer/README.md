# CNC Path Viewer — прототип 0.1

Автономное JS-приложение для просмотра траектории G-code, ориентированное на последующее встраивание в Windows через WebView2. Внешних библиотек, CDN и сетевой отправки файлов нет.

## Запуск

Откройте `index.html` в современном браузере — установка не нужна. Либо из этой папки выполните `npm start` и откройте http://127.0.0.1:4173. Требуется Node.js только для сервера и тестов. `npm test` запускает проверки геометрии парсера.

## Возможности

- Загрузка и перетаскивание `.nc`, `.gcode`, `.tap`, редактирование и сохранение текста.
- Ортографический 3D-вид с вращением и проекции XY/XZ/YZ. Canvas 2D отображает проекцию трёхмерных точек.
- Колесо — масштаб, перетаскивание — вращение, Shift + перетаскивание — сдвиг. Двойной щелчок — вписать.
- Выбор строки в редакторе, перемотка и воспроизведение по кадрам. Маркер показывает конец выбранного движения. Вся траектория остаётся видимой.
- Длины рабочих и быстрых движений, габариты, координаты в миллиметрах.
- Диагностика с остановкой перед неподдерживаемым или некорректным блоком. Уже построенная часть остаётся видимой.

## Диалект и границы

Поддерживаются G0/G1/G2/G3, G17/G18/G19, G20/G21, G90/G91, G90.1/G91.1, G94, дуги IJK и R, полные круги IJK и винтовые движения. G40/G49 принимаются как отключение коррекций; G80 отменяет модальное движение. По умолчанию: мм, G90, G17, G91.1, G0, начальная точка XYZ=0.

M0/M1/M3–M9 принимаются без моделирования станочных эффектов; M2/M30 завершают разбор. F используется как атрибут движения; S/T/N/O принимаются как метаданные, подпрограммы не исполняются. Воспроизведение идёт по числу кадров, не по подаче. Время обработки, съём материала, столкновения, кинематика станка и компенсации не рассчитываются.

G43 принимается для просмотра программной траектории с примечанием: коррекция длины по таблице станка не вычисляется. H в блоке G43 должен быть целым неотрицательным номером; G43 без H также принимается. Совмещённый блок G43 H1 G0Z5 выполняет программное перемещение G0. G43/G49 не заменяют модальный режим G1. Пример пользователя сохранён в examples/star9.nc.

G54–G59, G53, G92, G41/G42, G43.1/G43.2, циклы, макросы, подпрограммы и дополнительные оси пока не поддерживаются. При их обнаружении построение прекращается: показанная геометрия — только префикс программы. Координаты относятся к программе, не к фактической системе станка. Начальную позицию в дальнейшем следует передавать из командного процессора.

Допуск дискретизации дуг 0,02 мм, максимальный шаг 5°. Габариты дуг вычисляются по дискретизированным точкам и являются приближёнными; длина дуг рассчитывается аналитически. Допуск несовпадения радиусов: max(0,01 мм, 0,1% радиуса). Лимиты: файл 2 МБ / 50 000 строк, до 500 000 точек и 50 000 шагов одной дуги. Это ограничения прототипа; для крупных CAM-файлов следующий этап — Worker и WebGL.

## Интеграция WebView2

Загрузите `index.html` из каталога приложения; дождитесь `ready`. API не управляет станком. Будущий командный процессор остаётся источником фактического состояния исполнения.

```js
CNCViewer.load('G21 G90\nG0 Z5\nG1 X20 F300', 'part.nc');
CNCViewer.selectLine(3); // строки нумеруются с 1
CNCViewer.setView('xy'); // iso | xy | xz | yz
CNCViewer.fit();
CNCViewer.getState();
```

`selectLine` выбирает последнее движение на указанной строке или перед ней. Если движений до строки нет, выбор сохраняется. После редактирования `dirty: true` означает, что геометрия соответствует предыдущей версии текста; нажмите «Построить» / Ctrl+Enter. `load` немедленно перестраивает геометрию.

Из C# передавайте JSON через `CoreWebView2.PostWebMessageAsJson`, используя сериализацию, а не склейку JavaScript:

```csharp
using System.Text.Json;

webView.CoreWebView2.PostWebMessageAsJson(JsonSerializer.Serialize(new {
    type = "load", source = gcodeText, name = "part.nc"
}));
webView.CoreWebView2.PostWebMessageAsJson(JsonSerializer.Serialize(new {
    type = "selectLine", line = currentProgramLine
}));
// Также: { type: "setView", view: "iso" }, { type: "fit" }
```

Исходящие сообщения через `window.chrome.webview.postMessage`:

- `ready`: `{ type, version }`.
- `loaded`: `{ type, name, segments, complete, diagnostics }`.
- `selection`: `{ type, line, index, position: { x, y, z } }`.
- `error`: `{ type, message }` при некорректном входном сообщении.

Подпишитесь на `WebMessageReceived` до навигации. Эти же события доступны в браузере как `cnc:ready`, `cnc:loaded`, `cnc:selection`, `cnc:error` (`event.detail`). Обработчик хоста не должен возвращать `selection` обратно без проверки, чтобы не создавать цикл сообщений. C#-фрагмент — пример контракта; полноценный Windows-хост в эту поставку не входит.

## Файлы

`parser.js` — независимый парсер и геометрия; `app.js` — камера, интерфейс и API; `index.html` / `style.css` — представление; `parser.test.cjs` — тесты; `server.cjs` — необязательный локальный сервер.

Референс сценария: https://nc-viewer.ncnetic.com/. Семантика базовых G-команд сверялась с https://www.linuxcnc.org/docs/2.8/html/gcode/g-code.html. Прототип не является полным интерпретатором LinuxCNC или копией NCnetic.

## Кодировка файлов

При загрузке и перетаскивании распознаются UTF-8 и UTF-16 с BOM. Если байты не являются корректным UTF-8, используется Windows-1251. Это эвристика для старых CAM-файлов с русскими комментариями; другие однобайтовые кодировки автоматически не различаются. Кодировка показывается в нижней строке. Сохранение выполняется в UTF-8. Уже записанные в файл символы замены � не восстанавливаются: потребуется исходный файл.

## Пропуск неподдерживаемых команд

Галка «Игнорировать неподдерживаемые команды» под редактором выключена по умолчанию. Переключение сразу перестраивает программу. При включении весь блок с неизвестной G/M-командой (например G28 или M98) пропускается вместе с координатами, подачей и изменениями режимов. Пропуски перечислены в диагностике; дальнейшая траектория приблизительная, так как позиция и режимы станка могли измениться. Ошибки синтаксиса, геометрии и неподдерживаемые параметры без неизвестной G/M-команды по-прежнему останавливают разбор. Парсер: GCode.parse(source, {ignoreUnsupported: true}).
