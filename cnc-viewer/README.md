## Парсер

Поддерживаются G0/G1/G2/G3, плоскости G17/G18/G19, G20/G21, G90/G91, G90.1/G91.1, G94, центры дуг IJK и радиус R. G40/G49 отключают коррекции, G80 отменяет движение. Начальные значения: мм, G90, G17, G91.1, G0, XYZ=0.

M0/M1/M3–M9 не моделируют станочные эффекты; M2/M30 завершают разбор. F — атрибут движения; S/T/N/O принимаются как метаданные. G43 Hn принимается с примечанием: реальная коррекция длины не вычисляется. Подпрограммы не исполняются.

G54–G59, G53, G92, G41/G42, G43.1/G43.2, циклы, макросы и дополнительные оси останавливают разбор. Опция `ignoreUnsupported` пропускает целиком блок с неизвестной G/M-командой, включая его координаты и модальные изменения; дальнейшая геометрия приблизительная.

Допуск дискретизации дуг 0.02 мм, максимальный шаг 5°. Габариты приближённые, длина аналитическая. Допуск радиусов: max(0.01 мм, 0.1% радиуса). Максимум 500 000 точек и 50 000 шагов одной дуги.

## API просмотра

```js
CNCViewer.load('G21 G90\nG0 Z5\nG1 X20 F300', 'part.nc');
CNCViewer.selectLine(3);
CNCViewer.setView('xy'); // iso | xy | xz | yz
CNCViewer.fit();
CNCViewer.getState();
```

`selectLine` выбирает последнее движение на строке или перед ней. `dirty` означает изменения текста после построения. `load` перестраивает геометрию; во время работы контроллера загрузка запрещена.

События `cnc:ready`, `cnc:loaded`, `cnc:selection`, `cnc:error` доступны через `window.addEventListener`, данные — в `event.detail`. Для WebView2 сообщения дублируются через `window.chrome.webview.postMessage`.

Входящие сообщения хоста: `{type:'load', source, name}`, `{type:'selectLine', line}`, `{type:'setView', view}`, `{type:'fit'}`. Используйте JSON-сериализацию, а не склейку JavaScript. Событие selection не следует безусловно возвращать обратно хосту.

Этот API относится к просмотру. Подключение и команды станка реализованы отдельным `GRBL.Controller`; готового C#-хоста нет.

## Протокол

Каждая строка отправляется с LF. Один канал ожидает `ok/error`, независимый канал — отчёт `<…>` на `?`. Одинаковые ожидающие запросы статуса объединяются; период ограничен примерно 29 мс. Высокочастотные запросы не заполняют журнал. Частота обновления фактически зависит от платы и браузера.

Положение XYZ: `WPos` или `MPos − WCO`; обратное преобразование используется для машинной таблицы. WCO кэшируется, `$13` определяет перевод в мм. Маркер рисуется на отдельном Canvas, без полной перерисовки траектории при каждом отчёте.

Realtime-команды override передаются одиночными байтами, с проверкой `Ov:` между изменениями. Новая программа, Jog и настройки не запускаются параллельно с изменением override. Автоматического повторения неподтверждённой команды нет.
