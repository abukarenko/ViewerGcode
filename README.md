# ViewerGcode v0.1.0

Локальное приложение для просмотра G-code и управления CNC-контроллером GRBL через USB/Serial. Работает в браузере, без внешних библиотек и облачной передачи программ.

## Запуск на новом компьютере

### 1. Установите необходимое

- **Node.js 22 или новее** с npm: [официальный сайт](https://nodejs.org/). При установке на Windows оставьте добавление в PATH включённым.
- Настольный **Google Chrome или Microsoft Edge** с Web Serial.
- При необходимости — USB-драйвер вашей платы. В диспетчере устройств Windows плата должна появиться в разделе «Порты (COM и LPT)».

Git нужен только для клонирования; для ZIP-архива он не требуется. Python, компилятор, прошивальщик и `npm install` для запуска не нужны.

### 2. Скачайте приложение

Откройте [Releases](https://github.com/abukarenko/ViewerGcode/releases), скачайте `ViewerGcode-v0.1.0.zip` и распакуйте в обычную папку, например `C:\CNC\ViewerGcode`. Не запускайте изнутри архива.

Или клонируйте репозиторий:

```powershell
git clone https://github.com/abukarenko/ViewerGcode.git
cd ViewerGcode
```

### 3. Запустите сервер

Откройте терминал в распакованной папке проекта и выполните:

```powershell
cd cnc-viewer
node --version
npm start
```

Если PowerShell запрещает выполнение `npm.ps1`, используйте `npm.cmd start` либо запустите сервер напрямую:

```powershell
node server.cjs
```

Откройте **[http://127.0.0.1:4173](http://127.0.0.1:4173)** в Chrome/Edge. Оставьте терминал открытым. Для завершения сервера нажмите Ctrl+C в терминале. При следующем запуске достаточно снова выполнить `npm start`.

Сервер слушает только 127.0.0.1 — приложение доступно на этом компьютере. Для Serial используйте этот адрес, а не открытие HTML-файла двойным щелчком. Для просмотра без контроллера достаточно открыть `cnc-viewer/index.html`.

### 4. Соединитесь с контроллером

1. Подключите плату по USB. Закройте соединение с этим COM-портом в Candle, терминале или другом приложении.
2. В селекторе порта выберите **«Изменить порт…»**, затем нужную плату в окне браузера. Это выдаёт разрешение на доступ к устройству.
3. Выберите скорость, обычно **115200 бод**, и нажмите **«Соединить»**.
4. Приложение устанавливает DTR и RTS, ждёт запуска контроллера, читает `$$` и запрашивает `?`. После успешного открытия кнопка меняется на **«Разъединить»**.

При следующих запусках ранее разрешённый порт выбирается без повторного диалога, если браузер сохранил разрешение. Web Serial не сообщает номер COM: селектор показывает устройство и USB VID/PID. При нескольких одинаковых устройствах выбор может потребоваться повторно. Удаление разрешений браузера или другой профиль требует нового разрешения.

## Возможности

- Редактор G-code, загрузка `.nc`, `.gcode`, `.tap`, `.cnc`, `.txt`, перетаскивание файлов и сохранение.
- UTF-8, UTF-16 с BOM и распознавание Windows-1251 для старых CAM-файлов.
- Просмотр XYZ в 3D и проекциях XY/XZ/YZ; дуги G2/G3, IJK/R, винтовые перемещения.
- Поворот мышью, Shift + перетаскивание для сдвига, колесо для масштаба, двойной щелчок для вписывания.
- Пошаговый просмотр, диагностика и пропуск неподдерживаемых блоков по выбору пользователя.
- Serial: отправка программы, пауза, продолжение, сброс и журнал команд.
- Маркер инструмента по фактическим отчётам устройства, опрос с целевой частотой **35 Гц**.
- Рабочие и машинные координаты XYZ, расчёт через WCO, перевод дюймовых отчётов в мм.
- Jog XYZ: один клик — один относительный шаг, шаг 0.01–100 мм, подача 1–10000 мм/мин.
- Настройки GRBL с русскими пояснениями и расширениями [Mash3_grbl](https://github.com/abukarenko/Mash3_grbl).
- Коррекция рабочей подачи 10–200% и быстрых перемещений 25/50/100%.

## Работа с программой

Откройте файл, изучите диагностику и нажмите «Построить» после редактирования (Ctrl+Enter). «Отправить на станок» отправляет **весь текст редактора с первой строки**, независимо от выбранного кадра. Галка пропуска неподдерживаемых команд влияет только на предпросмотр, а не на отправку.

Передача покадровая: **строка → ok → опрос ? до Idle → следующая строка**. Это создаёт остановки между блоками; непрерывного заполнения планировщика в этом релизе нет. `ok` означает принятие команды. Пройденные блоки отмечаются отдельно от фактической позиции инструмента.

При ошибке или потере связи очередь останавливается; автоматического повтора строк нет. Ожидание `ok` ограничено 120 секундами, отдельного отчёта состояния — 3 секундами. Само движение и пауза могут длиться дольше. При медленных ответах частота опроса снижается без накопления запросов.

## Органы управления

| Кнопка / регулятор | Действие |
|---|---|
| Пауза / Продолжить | Команды `!` / `~` |
| Сброс GRBL | Отмена очереди, Ctrl-X, ожидание стартового сообщения, `$X`, проверка Idle |
| Jog X/Y/Z | `$J=G91 G21 …`; остановка кнопкой ⊘ или Esc (байт 0x85) |
| Ноль XY / Ноль Z | `G92 X0 Y0` / `G92 Z0`, изменение рабочих координат |
| Безопасный Z | `G53 G90 G0 Z0`, быстрый ход к машинному Z=0 |
| Щуп Z | Двойное касание, рабочий Z=0, подъём на 5 мм |
| Рабочая подача / Быстрый ход | Realtime-команды GRBL, подтверждение фактических процентов через `Ov:`; снятие галочки возвращает 100% |

«Безопасный Z» требует корректного машинного нуля: название кнопки не означает, что путь автоматически проверен на препятствия. Программный сброс не заменяет аппаратный аварийный выключатель. Закрытие браузера не гарантирует остановку станка.

### Щуп Z

Цикл по примеру Candle:

```gcode
G21 G91 G94
G38.2 Z-30 F100
G0 Z1
G38.2 Z-2 F10
G92 Z0
G91 G0 Z5
```

Перед циклом читаются `$G` и настройки. После успеха восстанавливаются единицы, режим координат, режим и значение подачи, исходный G0/G1/G80. Начальный G94 явно задаёт мм/мин. Режим дуги или probing перед запуском не допускается, поскольку его нельзя восстановить отдельной строкой без движения. При ошибке следующие команды не отправляются; временные режимы могут остаться активными. Толщина пластины не учитывается. В Mash3_grbl при `$7=1` probing запрещён.

### Параметры GRBL

«Параметры GRBL» читает `$$`. Редактируйте значения, проверьте список изменений и нажмите «Применить». После каждой записи ожидается `ok`, затем настройки перечитываются для проверки. При частичной ошибке показывается число подтверждённых записей. Параметры сохраняются в памяти платы.

В окне также доступны `$I` (версия), `$G` (режимы), `$#` (смещения) и `$N` (стартовые блоки). Справочник Mash3_grbl включает `$7`, настройки поворотной оси A и бит A=8 в масках направления и STEP. Неизвестные параметры не получают предположительных описаний.

## Ограничения первого релиза

- Предпросмотр и контроллер имеют разные возможности. G53/G54–G59/G92, probing, дополнительные оси и ряд коррекций не моделируются просмотрщиком, хотя контроллер может их выполнять.
- Визуализируется XYZ; ось A видна в исходном текстовом отчёте, но не в 3D.
- Нет проверки столкновений, снятия материала, кинематики и времени обработки.
- До получения WCO/единиц координаты могут отображаться как «—».
- Ограничения файла: 2 МБ или 50 000 строк; отправляемая строка — до 79 символов после удаления комментариев и пробелов.
- Собственный Windows-хост WebView2 и локальный Serial-мост не входят в поставку. Web Serial в таком хосте зависит от его поддержки.

## Если не запускается

| Симптом | Что проверить |
|---|---|
| `node` / `npm` не найден | Установите Node.js, откройте новый терминал, проверьте `node --version` |
| PowerShell блокирует npm | Используйте `npm.cmd start` или `node server.cjs` |
| `EADDRINUSE` | Порт 4173 уже занят; если сервер уже запущен, откройте его адрес |
| Нет платы в списке | USB-кабель с передачей данных, драйвер, диспетчер устройств, разрешение через «Изменить порт…» |
| Порт не открывается | Освободите его в другом приложении, проверьте USB-соединение |
| Тайм-аут GRBL | Скорость, прошивка, питание; кнопка соединения ждёт ответы `$$` и `?` |
| `Alarm` | Устраните причину; кнопка сброса выполняет Ctrl-X и `$X`, но не поиск машинного нуля |
| Старый интерфейс после обновления | Обновите страницу с Ctrl+F5 после остановки работы |

## Проверка и разработка

```powershell
cd cnc-viewer
npm test
```

Первый релиз проверен 50 автоматическими тестами. На плате COM12 проверялись подключение, чтение настроек, повторное открытие порта и 105 ответов состояния с частотой 34.8 Гц. Автоматические проверки движений выполнялись на имитаторе; эти тесты не являются проверкой механики конкретного станка.
